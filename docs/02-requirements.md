# 需求规格说明书

## 1. 项目定位

本项目是一个家政服务类小程序平台，覆盖月嫂、保姆、育婴师、居家养老、保洁师、钟点工、成长陪伴师、家电清洗师等服务。用户可以查找服务人员、发布用工需求、预约面试、查看后台推荐阿姨、购买团购服务、查看合同和订单。

## 2. 用户角色

第一版包含两个角色：

- 普通用户：通过微信小程序使用服务。
- 管理员：通过管理后台维护全部业务数据。

第一版不做服务人员独立登录端。服务人员资料由管理员后台录入和维护。

## 3. 小程序端页面

底部 Tab：

- 首页
- 合同
- 找阿姨
- 消息
- 我的

### 3.1 首页

首页展示：

- 顶部轮播图。
- 签约成功提示，例如“恭喜用户：某某签约成功”。
- 服务分类入口。
- 团购活动列表。
- 浮动联系客服按钮。

服务分类：

- 月嫂
- 保姆
- 育婴师
- 居家养老
- 保洁师
- 钟点工
- 成长陪伴师
- 家电清洗师

### 3.2 找阿姨

用户可以按分类进入服务人员列表。

列表筛选：

- 关键词搜索：按姓名搜索。
- 年龄筛选。
- 学历筛选。
- 工资筛选。
- 地区筛选。

列表字段：

- 头像。
- 姓名。
- 所在城市。
- 年龄。
- 工作经验。
- 服务类型。
- 学历。
- 薪资范围。
- 标签。

### 3.3 阿姨详情

详情页展示：

- 基础资料。
- 服务说明。
- 证书展示。
- 照片展示。
- 工作经历。
- 服务流程。
- 用户评价。
- 收藏按钮。
- 分享按钮。
- 预约面试按钮。
- 联系客服按钮。

用户点击预约面试后，系统生成预约记录，管理员后台跟进。

### 3.4 发布需求

用户可以发布找阿姨需求。

字段：

- 标题。
- 服务类型。
- 月嫂周期：26 天、42 天、52 天、78 天。
- 姓名。
- 电话。
- 性别。
- 是否住家。
- 薪资待遇。
- 所在区域。
- 详细地址。
- 补充说明。

需求提交后状态为“审核中”。管理员审核通过后，可以给需求推荐一个或多个服务人员。用户在需求详情中查看推荐阿姨列表。

### 3.5 团购

团购服务用于购买标准化服务，例如保洁、老人陪护、家电清洗。

团购列表展示：

- 商品封面图。
- 商品名称。
- 团购价。
- 单独购买价。
- 已售数量。
- 拼团倒计时。

团购详情展示：

- 商品轮播图。
- 团购价和原价。
- 已售数量。
- 消费须知。
- 有效期。
- 服务保障。
- 产品介绍。
- 正在拼团的人。
- 拼团购买按钮。
- 单独购买按钮。

购买方式：

- 单独购买：直接生成团购订单。
- 拼团购买：发起拼团或加入别人拼团。

第一版不接真实微信支付，点击支付后模拟支付成功。

### 3.6 合同

合同页展示用户相关合同。

状态：

- 已签署。
- 已终止。

第一版合同由后台上传文件，用户端查看合同状态和文件。

### 3.7 消息

第一版消息中心展示系统消息。

消息类型：

- 需求审核通知。
- 推荐阿姨通知。
- 预约面试通知。
- 合同通知。
- 团购订单通知。

### 3.8 我的

我的页面包含：

- 手机号快捷登录。
- 个人资料。
- 团购订单。
- 服务订单。
- 我的需求。
- 我的邀约。
- 我的收藏。
- 我的推荐。
- 常见问题。
- 用户协议。
- 隐私政策。
- 联系客服。
- 关于我们。

## 4. 管理后台功能

后台第一版只有一个管理员角色，可以操作全部模块。

后台模块：

- 登录。
- 控制台。
- 用户管理。
- 服务分类管理。
- 服务人员管理。
- 需求管理。
- 预约面试管理。
- 推荐阿姨管理。
- 合同管理。
- 服务订单管理。
- 团购商品管理。
- 拼团管理。
- 团购订单管理。
- 内容管理。
- 文件管理。
- 系统配置。

## 5. 第一版不做的内容

- 服务人员独立登录端。
- 在线聊天。
- 真实微信支付。
- 真实退款。
- 电子签章。
- 复杂财务结算。
- 多管理员角色权限。
- 分销、返佣、会员等级。
