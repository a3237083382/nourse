# 开发计划与验收标准

## 0. 使用方式

本文档是后续开发的唯一总任务清单。系统里所有开发任务、验证任务、剩余问题都统一放在这里维护。

其他文档只保留需求、设计、接口、阶段说明或验证记录，不再作为 Todo 看板使用。如果其他文档和本文档出现任务状态冲突，以本文档为准。

打勾规则：

- 开始任务前，先确认本阶段依赖是否已完成。
- 完成代码后，运行对应测试或手工验证。
- 验证通过后，更新本文档对应 TODO。
- 不再维护 `docs/00-project-requirements-overview.md`、`docs/11-admin-module-development-work-plan.md`、`docs/12-miniapp-page-development-work-plan.md` 等文档里的独立 Todo。
- 最终回复里说明测试结果和已打勾的任务。

禁止事项：

- 没测试不打勾。
- 没完成不打勾。
- 验证失败不打勾。
- 不为省事跳过本文档更新。
- 不做本文档之外的扩展功能，除非用户明确要求。
