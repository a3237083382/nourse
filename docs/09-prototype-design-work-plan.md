# 原型设计工作文档

## 1. 阶段目的

原型设计阶段用于把需求转成可以确认的页面结构和业务操作路径。这个阶段不写正式业务代码，重点是确认小程序端、管理后台端每个页面要展示什么、用户怎么操作、按钮跳到哪里、状态怎么变化。

原型确认后，后续数据库设计、接口设计、后台开发和小程序开发都按原型推进，避免边写代码边反复改业务方向。

## 6. 原型设计规则

- 先做业务流程，再做视觉细节。
- 管理后台以效率为主，优先列表、筛选、表单、弹窗、详情页。
- 小程序端以用户路径清晰为主，避免堆太多后台字段。
- 不复制目标小程序的品牌、图片、Logo、文案。
- 第一版不加入真实支付、在线聊天、电子签章、服务人员端、多角色权限。
- 图片上传统一走后端 OSS，原型中只表达上传入口和展示位置。

## 7. 交付验收标准

- 每个核心页面都有明确入口和出口。
- 每个核心业务流程能从开始走到结束。
- 页面字段和 `docs/02-requirements.md` 不冲突。
- 状态名称和 `docs/03-business-flows.md` 不冲突。
- 后台原型能支撑小程序所需展示数据。
- 未确定内容已记录为待确认项。

核心入口规则：

- 首页服务分类、找阿姨 Tab、推荐阿姨列表都可以进入阿姨详情。

- 我的需求详情展示审核状态、跟进信息和推荐阿姨列表。
- 合同、服务订单、团购订单都从我的页或对应 Tab 进入详情。
- 第一版不做在线聊天，所有“联系客服”只保留平台客服入口。

- 第一版只有一个管理员角色，不设计多角色菜单权限。

## 10. 小程序端原型说明

### 10.1 首页

入口：底部首页 Tab。

展示内容：

- 顶部轮播图：图片、标题、跳转目标。
- 签约成功提示：用户昵称或脱敏手机号、服务类型、签约文案。
- 服务分类入口：月嫂、保姆、育婴师、居家养老、保洁师、钟点工、成长陪伴师、家电清洗师。
- 团购推荐区：商品封面、商品名称、团购价、单独购买价、已售数量。
- 浮动联系客服按钮。

按钮和跳转：

- 点击分类：进入找阿姨列表，并带入分类筛选。
- 点击团购商品：进入团购详情。
- 点击联系客服：打开平台客服入口。

状态和空状态：

- 轮播为空：隐藏轮播区或展示通用占位。
- 签约提示为空：隐藏提示区。
- 团购推荐为空：展示“暂无团购活动”。

### 10.2 找阿姨列表

入口：首页分类入口、底部找阿姨 Tab、推荐阿姨列表。

筛选字段：

- 关键词：按姓名搜索。
- 服务分类。
- 年龄范围。
- 学历。
- 薪资范围。
- 城市、区县。

列表字段：

- 头像。
- 姓名。
- 所在城市。
- 年龄。
- 工作经验。
- 服务类型。
- 学历。
- 薪资范围。
- 标签。

按钮和跳转：

- 点击服务人员卡片：进入阿姨详情。
- 点击重置：清空筛选条件。
- 点击搜索：刷新列表。

状态和空状态：

- 首次进入默认展示已上架服务人员。
- 无结果时展示“暂无符合条件的服务人员”，保留筛选重置入口。
- 下架服务人员不在公开列表展示。

### 10.3 阿姨详情

入口：找阿姨列表、推荐阿姨列表、我的收藏。

展示内容：

- 基础资料：头像、姓名、城市、年龄、经验、学历、薪资范围、服务类型。
- 服务说明。
- 标签。
- 证书展示。
- 照片展示。
- 工作经历。
- 服务流程。
- 用户评价占位。

按钮和跳转：

- 收藏/取消收藏：登录后生效，未登录引导登录。
- 分享：打开小程序分享能力。
- 预约面试：进入预约面试页。
- 联系客服：打开平台客服入口。

状态和空状态：

- 证书、照片、经历为空时对应模块隐藏或展示轻量空状态。
- 服务人员已下架时，详情页展示“该服务人员暂不可预约”，隐藏预约按钮。

### 10.4 发布需求

入口：我的页、我的需求列表、首页快捷入口。

表单字段：

- 标题。
- 服务类型。
- 月嫂周期：26 天、42 天、52 天、78 天，仅月嫂类展示。
- 姓名。
- 电话。
- 性别。
- 是否住家。
- 薪资待遇。
- 所在区域。
- 详细地址。
- 补充说明。

按钮和跳转：

- 提交需求：创建需求，成功后进入我的需求详情。
- 取消：返回上一页。

状态和校验：

- 必填：标题、服务类型、姓名、电话、所在区域、详细地址。
- 提交成功后审核状态为“审核中”，后台跟进状态为“待跟进”。
- 提交失败时保留用户已填内容。

### 10.5 我的需求列表和详情

入口：我的页“我的需求”。

列表字段：

- 需求标题。
- 服务类型。
- 所在区域。
- 审核状态：审核中、已通过、已拒绝、已取消。
- 提交时间。

详情字段：

- 需求基础信息。
- 审核状态。
- 后台跟进状态：待跟进、已联系、已匹配、已签约、已关闭。
- 后台备注展示为对用户可见的处理说明，内部备注不展示。
- 推荐阿姨列表。

按钮和跳转：

- 发布新需求：进入发布需求页。
- 查看详情：进入我的需求详情。
- 查看推荐阿姨：进入推荐阿姨列表或在详情内展开。
- 取消需求：仅审核中需求可取消。

状态和空状态：

- 无需求：展示发布需求入口。
- 已拒绝：展示拒绝说明或通用提示。
- 已通过且暂无推荐：展示“平台正在为你匹配合适阿姨”。

### 10.6 推荐阿姨和预约面试

推荐阿姨列表入口：我的需求详情。

推荐列表字段：

- 服务人员头像、姓名、服务类型、城市、年龄、经验、学历、薪资。
- 推荐理由。
- 推荐状态：已推荐、用户已查看、已预约面试、已忽略。
- 排序。

推荐按钮和跳转：

- 查看阿姨详情：进入阿姨详情。
- 预约面试：进入预约面试页，并带入服务人员和需求。
- 忽略：标记为已忽略。

预约面试页字段：

- 服务人员信息。
- 来源需求，可为空。
- 联系人。
- 联系电话。
- 备注。

预约状态：

- 待处理。
- 已联系。
- 已安排。
- 已完成。
- 已取消。

预约按钮和跳转：

- 提交预约：生成预约记录，成功后进入我的邀约详情或列表。
- 返回详情：返回阿姨详情。

### 10.7 合同和服务订单

合同列表入口：底部合同 Tab、我的页“我的合同”。

合同列表字段：

- 合同编号。
- 合同标题。
- 服务人员。
- 关联需求或服务订单。
- 状态：已签署、已终止。
- 签署时间。

合同详情字段：

- 合同基本信息。
- 服务人员信息。
- 合同文件：PDF 或图片。
- 状态和时间。

服务订单入口：我的页“服务订单”。

服务订单字段：

- 订单号。
- 服务类型。
- 服务人员。
- 服务开始日期。
- 服务结束日期。
- 金额。
- 状态：待开始、进行中、已完成、已转让。
- 关联合同入口。

空状态：

- 无合同：展示“暂无合同”。
- 无服务订单：展示“暂无服务订单”。

### 10.8 团购

团购列表入口：首页团购推荐、我的页、业务入口。

团购列表字段：

- 商品封面图。
- 商品名称。
- 团购价。
- 单独购买价。
- 已售数量。
- 拼团倒计时或活动有效提示。

团购详情字段：

- 商品轮播图。
- 团购价和原价。
- 已售数量。
- 消费须知。
- 有效期。
- 服务保障。
- 产品介绍。
- 正在拼团的人。
- 还差几人成团。

按钮和跳转：

- 单独购买：选择规格和数量，模拟支付后生成待使用订单。
- 拼团购买：选择规格和数量，模拟支付后发起拼团，订单状态为待分享。
- 去拼团：加入别人正在拼的团，模拟支付后加入拼团。

拼团状态：

- 拼团中。
- 拼团成功。
- 拼团失败。
- 已取消。

团购订单状态：

- 待分享。
- 待使用。
- 已使用。
- 到期。
- 售后。

边界说明：

- 满员后拼团状态变为拼团成功，参与订单变为待使用。
- 第一版支付只做模拟支付成功，不接微信支付。
- 超过成团人数时禁止继续加入。

### 10.9 消息和我的页面

消息列表入口：底部消息 Tab、我的页消息入口。

消息类型：

- 需求审核通知。
- 推荐阿姨通知。
- 预约面试通知。
- 合同通知。
- 团购订单通知。

消息字段：

- 标题。
- 内容摘要。
- 消息类型。
- 是否已读。
- 创建时间。

按钮和跳转：

- 点击消息：进入对应业务详情，或仅展示消息详情。
- 标记已读：消息状态变为已读。

我的页面内容：

- 手机号快捷登录。
- 个人资料。
- 团购订单。
- 服务订单。
- 我的需求。
- 我的邀约。
- 我的收藏。
- 我的推荐。
- 常见问题。
- 用户协议。
- 隐私政策。
- 联系客服。
- 关于我们。

## 11. 管理后台原型说明

- 图标。

- 是否启用。

操作：

- 新增。

- 启用/禁用。

- 学历。
- 薪资。
- 状态：草稿、上架、下架。
- 是否推荐。

筛选：

- 姓名。
- 服务分类。
- 城市。
- 状态。
- 是否推荐。

编辑字段：

- 基础资料。

- 上传证书。

- 添加工作经历。

### 11.3 用户需求、推荐和预约

推荐字段：

- 联系电话。
- 服务人员。
- 来源需求。
- 状态。

预约操作：

- 查看关联合同。
- 添加后台备注。

状态规则：

- 合同只支持已签署、已终止。
- 服务订单只支持待开始、进行中、已完成、已转让。
- 第一版服务订单由管理员创建，不由服务人员接单生成。

### 11.5 团购商品、拼团和团购订单

团购商品入口：团购管理 / 团购商品。

商品字段：

- 商品名称。
- 封面图。
- 轮播图。
- 原价。
- 单独购买价。
- 拼团价。
- 成团人数。
- 有效天数。
- 消费须知。
- 服务保障。
- 产品介绍。
- 上架状态。

商品操作：

- 新增商品。
- 编辑商品。
- 上架/下架。
- 查看拼团记录。
- 查看订单。

拼团入口：团购管理 / 拼团记录。

拼团列表字段：

- 商品。
- 团长用户。
- 成团人数。
- 已加入人数。
- 过期时间。
- 状态。

拼团操作：

- 查看团成员。
- 手动取消。
- 查看关联订单。

团购订单入口：订单管理 / 团购订单。

订单字段：

- 订单号。
- 用户。
- 商品。
- 购买方式：单独购买、拼团购买。
- 金额。
- 数量。
- 状态。
- 有效期。

订单操作：

- 查看详情。
- 修改状态。
- 标记已使用。
- 标记售后。

状态规则：

- 单独购买模拟支付后生成待使用订单。
- 发起拼团模拟支付后生成待分享订单和拼团中记录。
- 加入拼团满员后，拼团状态变为拼团成功，参与订单变为待使用。

## 12. 核心页面流转说明

### 12.1 找阿姨到预约面试

```text
首页/找阿姨
-> 选择服务分类或筛选条件
-> 找阿姨列表
-> 阿姨详情
-> 收藏/分享/联系客服
-> 预约面试
-> 提交联系信息
-> 后台生成预约记录
-> 管理员线下跟进并修改状态
```

### 12.2 发布需求到推荐阿姨

```text
我的/发布需求
-> 填写需求信息
-> 提交需求
-> 需求状态为审核中
-> 管理员审核通过或拒绝
-> 审核通过后管理员推荐一个或多个阿姨
-> 用户在我的需求详情查看推荐列表
-> 用户进入阿姨详情并预约面试
```

### 12.3 合同和服务订单

```text
管理员线下确认服务
-> 后台创建合同并上传 PDF/图片
-> 用户在合同页查看合同
-> 后台创建服务订单
-> 用户在服务订单页查看服务进度
-> 管理员按线下服务进展修改订单状态
```

### 12.4 团购闭环

```text
管理员创建并上架团购商品
-> 用户进入团购详情
-> 单独购买或拼团购买
-> 模拟支付成功
-> 单独购买生成待使用订单
-> 发起拼团生成待分享订单和拼团中记录
-> 其他用户加入拼团
-> 满员后拼团成功
-> 参与订单变为待使用
```

- 不做服务人员独立登录端。
- 不做服务人员接单、改订单状态。
- 不做多管理员角色权限。
- 不做分销、返佣、会员等级。
- 不做短信、公众号模板消息、订阅消息。
- 不复制目标小程序品牌、图片、Logo、文案或私有接口。
