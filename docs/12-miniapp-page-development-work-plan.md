# 小程序页面开发工作文档

## 1. 阶段目的

小程序页面开发阶段用于把已确认的用户端原型接入真实后端接口，让普通用户可以浏览服务、发布需求、查看推荐、预约面试、查看合同和订单、参与团购。

小程序端第一版以主流程可用为目标，不追求复杂动效和营销玩法。

## 5. 页面开发规则

- 页面数据必须来自后端接口或明确的临时 mock。
- 只在接口未完成时使用 mock，并在文档中标明。
- 列表页要处理加载中、空数据、失败、分页或下拉刷新。
- 表单页要做必填校验和提交中状态。
- 用户操作成功后要能看到状态变化。
- 图片展示优先使用 OSS 返回 URL。
- 小程序端不能保存 OSS AccessKey。
- 不复制目标小程序图片、品牌文案和私有素材。

## 6. 微信小程序注意事项

- 本地开发可在微信开发者工具中勾选不校验合法域名。
- 真机和上线前必须配置合法 `request`、`uploadFile`、`downloadFile` 域名。
- OSS 图片域名需要加入 `downloadFile` 合法域名。
- 后端 API 域名需要加入 `request` 和 `uploadFile` 合法域名。
- 第一版不接真实微信支付，支付按钮走模拟支付接口。

## 7. 已完成范围

当前已完成并验证：

- 小程序请求封装：`miniapp/src/services/request.js`。
- 小程序接口封装：`miniapp/src/services/api.js`。
- 开发环境 API 地址：默认指向 `http://localhost:8081`。
- 登录占位流程：使用后端 mock login，保存 token 和用户信息。
- 登录状态处理：需要登录的收藏、发布需求、预约面试等操作会先引导登录。
- 首页页面：展示服务分类、签约提示、团购推荐、推荐服务人员。
- 找阿姨列表页面：支持分类、关键词、城市、学历、年龄、薪资筛选和分页加载。
- 阿姨详情页面：展示基础信息、标签、证书、照片、经历，支持收藏/取消收藏入口。
- 我的页面：展示登录状态、收藏入口和第一版业务入口占位。
- 发布需求页面：支持服务类型、月嫂周期、姓名、电话、性别、是否住家、薪资、区域、地址、补充说明字段，并提交到后端。
- 我的需求页面：支持分页查看需求列表、状态展示和进入需求详情。
- 推荐阿姨展示：需求详情页展示后台推荐阿姨列表，并可跳转阿姨详情。
- 预约面试提交：阿姨详情页可进入预约表单，提交后生成预约记录。
- 我的邀约页面：支持查看预约列表和预约详情，展示后台处理状态和备注。

## 8. 验证记录

已完成页面通过以下验证：

- 小程序构建：`npm run build:mp-weixin`，结果通过。
- 首页接口：`GET /api/app/home` 返回 `code = 200`，服务分类数量为 8，推荐服务人员数量为 1。
- 找阿姨列表接口：`GET /api/app/staff?pageNum=1&pageSize=5` 返回 `code = 200`，可见服务人员数量为 1。
- 阿姨详情接口：`GET /api/app/staff/6` 返回 `code = 200`。
- 需求发布接口：`POST /api/app/demands` 返回需求 ID，随后详情状态为 `PENDING/TO_FOLLOW`。
- 我的需求接口：`GET /api/app/demands` 返回当前用户需求列表。
- 推荐阿姨接口：后台推荐后，`GET /api/app/demands/{id}/recommendations` 返回推荐列表，双推荐场景按 `sortNo` 升序返回。
- 小程序构建：`npm run build:mp-weixin`，结果通过。
- 预约面试接口：`POST /api/app/interviews` 返回预约 ID，`GET /api/app/interviews` 和 `GET /api/app/interviews/{id}` 可读取当前用户预约记录。

说明：当前验证是命令行构建和接口验证，尚未完成微信开发者工具预览和真机验证。
