# 小程序页面开发工作文档

## 1. 阶段目的

小程序页面开发阶段用于把已确认的用户端原型接入真实后端接口，让普通用户可以浏览服务、发布需求、查看推荐、预约面试、查看合同和订单、参与团购。

小程序端第一版以主流程可用为目标，不追求复杂动效和营销玩法。

## 4. 开发顺序

1. 请求封装、接口地址、错误提示。
2. 用户登录占位和本地用户状态。
3. 首页。
4. 找阿姨列表。
5. 阿姨详情。
6. 发布需求。
7. 我的需求和推荐阿姨。
8. 预约面试。
9. 合同列表和详情。
10. 服务订单列表和详情。
11. 团购列表和详情。
12. 单独购买、发起拼团、加入拼团。
13. 团购订单。
14. 消息列表。
15. 我的页面。

## 5. 页面开发规则

- 页面数据必须来自后端接口或明确的临时 mock。
- 只在接口未完成时使用 mock，并在页面顶部或文档中标明。
- 列表页要处理加载中、空数据、失败、分页或下拉刷新。
- 表单页要做必填校验和提交中状态。
- 用户操作成功后要能看到状态变化。
- 图片展示优先使用 OSS 返回 URL。
- 小程序端不能保存 OSS AccessKey。
- 不复制目标小程序图片、品牌文案和私有素材。

## 6. 微信小程序注意事项

- 本地开发可在微信开发者工具中勾选不校验合法域名。
- 真机和上线前必须配置合法 request、uploadFile、downloadFile 域名。
- OSS 图片域名需要加入 downloadFile 合法域名。
- 后端 API 域名需要加入 request 和 uploadFile 合法域名。
- 第一版不接真实微信支付，支付按钮走模拟支付接口。

## 7. 交付验收标准

- 小程序能在微信开发者工具打开。
- 首页能展示后台配置数据。
- 找阿姨列表和详情能展示后台服务人员数据。
- 用户能提交需求。
- 用户能查看需求和推荐阿姨。
- 用户能预约面试。
- 用户能查看合同和订单。
- 用户能浏览团购并完成模拟购买或拼团。
- 消息和我的页面能显示基础信息。
