# 家政到家服务系统使用说明

## 1. 系统角色说明

本系统当前按三个业务角色使用：

- 管理员：使用管理后台，负责维护服务分类、阿姨资料、审核客户需求、推荐阿姨、处理预约、创建合同、维护订单、配置内容和查看消息触发结果。
- 客户：使用微信小程序，负责浏览服务、找阿姨、发布需求、查看推荐、预约面试、查看合同、查看服务订单、购买团购服务和查看系统消息。
- 保姆阿姨/服务人员：当前第一版没有独立登录端。阿姨资料由管理员录入，阿姨主要在线下配合平台完成面试、服务和资料更新。

当前版本不包含：阿姨独立登录接单、在线聊天、真实微信支付、真实退款、电子签章、分销返佣。

## 2. 管理员如何使用

### 2.1 登录后台

1. 打开管理后台：`http://localhost:8082/`
2. 输入管理员用户名和密码。
3. 登录后进入首页控制台。
4. 左侧菜单只保留本系统相关业务菜单。

本地开发环境：

- 后端地址：`http://localhost:8081/`
- 管理后台地址：`http://localhost:8082/`
- 小程序请求后端：`http://localhost:8081`

### 2.2 维护服务分类

入口：家政管理 -> 服务分类

管理员可以：

- 新增服务分类。
- 编辑分类名称、排序。
- 启用或禁用分类。

第一版保留的服务分类：

- 月嫂
- 保姆
- 育婴师
- 居家养老
- 保洁师
- 钟点工
- 成长陪伴师
- 家电清洗师

### 2.3 维护服务人员/阿姨资料

入口：家政管理 -> 服务人员

管理员可以：

- 新增阿姨资料。
- 编辑姓名、分类、年龄、学历、经验、地区、薪资、服务说明。
- 设置上架或下架。
- 设置是否首页推荐。
- 维护标签、证书、照片、工作经历。

客户只能在小程序查看已上架的阿姨。下架阿姨不会出现在客户公开列表中。

### 2.4 审核客户需求

入口：用户需求 -> 用户需求

客户发布需求后，默认状态是“审核中”。

管理员可以：

- 查看需求详情。
- 审核通过。
- 审核拒绝。
- 修改跟进状态。

审核结果会同步到客户的小程序“我的需求”，并生成系统消息。

### 2.5 推荐阿姨

入口：用户需求 -> 用户需求 -> 详情/推荐

需求审核通过后，管理员可以给客户推荐一个或多个阿姨。

推荐后：

- 客户在小程序“我的需求详情”能看到推荐阿姨列表。
- 客户可以从推荐列表进入阿姨详情。
- 客户可以预约面试。
- 系统会生成“新的阿姨推荐”消息。

### 2.6 处理预约面试

入口：预约面试 -> 预约面试

客户从阿姨详情提交预约后，后台会生成预约记录。

管理员可以：

- 查看预约人、电话、服务人员、来源需求。
- 修改预约状态。
- 添加后台备注。

预约状态：

- 待处理
- 已联系
- 已安排
- 已完成
- 已取消

管理员线下联系客户和阿姨，确认实际面试时间。

### 2.7 创建合同

入口：合同管理 -> 合同列表

管理员可以：

- 新增合同。
- 绑定客户、服务人员、需求或服务订单。
- 填写合同编号、合同标题。
- 上传或填写合同文件地址。
- 修改合同状态。

合同状态：

- 已签署
- 已终止

创建合同后，客户可以在小程序“合同”页查看，系统也会生成“合同已创建”消息。

### 2.8 维护服务订单

入口：订单管理 -> 服务订单

管理员可以：

- 新增服务订单。
- 绑定客户、服务人员、服务分类和需求。
- 填写服务金额、开始日期、结束日期、后台备注。
- 修改订单状态。

服务订单状态：

- 待开始
- 服务中
- 已完成
- 已取消

客户可以在小程序“我的 -> 服务订单”查看订单。

### 2.9 维护团购商品

入口：团购管理 -> 团购商品

管理员可以：

- 新增团购商品。
- 编辑商品名称、原价、单买价、拼团价、成团人数、有效天数。
- 编辑购买须知、服务保障、商品介绍。
- 上架或下架商品。

上架商品会展示在小程序首页团购推荐和团购列表。

### 2.10 查看拼团和团购订单

入口：

- 团购管理 -> 拼团记录
- 团购管理 -> 团购订单

管理员可以：

- 查看发起拼团、加入拼团、拼团成功记录。
- 查看团购订单。
- 修改团购订单状态。

团购订单状态：

- 待分享
- 待使用
- 已使用
- 到期
- 售后

拼团满员后，拼团状态自动变为“拼团成功”，参与订单变为“待使用”。

### 2.11 维护内容配置

入口：内容管理 -> 内容配置

管理员可以维护：

- 首页轮播
- 签约动态
- 常见问题
- 用户协议
- 隐私政策
- 关于我们

客户可以在小程序首页和“我的”页面看到这些内容。

## 3. 客户如何使用小程序

### 3.1 打开小程序

本地测试时：

1. 打开微信开发者工具。
2. 导入小程序构建目录：`miniapp/dist/build/mp-weixin`
3. 确认后端 `http://localhost:8081` 正在运行。
4. 编译运行小程序。

### 3.2 首页

客户可以在首页看到：

- 首页轮播。
- 服务分类。
- 签约动态。
- 团购推荐。
- 联系客服入口。

点击服务分类，会进入对应的找阿姨列表。

### 3.3 找阿姨

入口：底部 Tab -> 找阿姨

客户可以：

- 搜索阿姨姓名或服务说明。
- 按服务分类筛选。
- 按年龄、学历、工资、地区筛选。
- 查看阿姨列表。
- 进入阿姨详情。

阿姨详情页可以查看：

- 基础资料。
- 薪资范围。
- 服务说明。
- 标签。
- 证书记录。
- 照片。
- 工作经历。
- 平台核验说明。

客户可以在详情页进行：

- 收藏。
- 分享。
- 联系客服。
- 预约面试。

### 3.4 发布需求

入口：

- 首页快捷入口。
- 我的 -> 发布需求。

客户填写：

- 服务类型。
- 月嫂周期。
- 联系人。
- 联系电话。
- 性别要求。
- 是否住家。
- 预算薪资。
- 城市、地区、地址。
- 补充说明。

提交后需求状态为“审核中”。

### 3.5 查看我的需求和推荐阿姨

入口：我的 -> 我的需求/我的推荐

客户可以查看：

- 审核中需求。
- 已通过需求。
- 已拒绝需求。
- 已取消需求。
- 后台推荐的阿姨列表。

管理员推荐阿姨后，客户可以：

1. 进入需求详情。
2. 查看推荐阿姨。
3. 点击阿姨进入详情。
4. 预约面试。

### 3.6 预约面试

客户从阿姨详情页点击“预约面试”。

需要填写：

- 联系人。
- 联系电话。
- 期望面试时间。
- 面试方式。
- 面试地址。
- 服务重点。

提交后，平台工作人员会线下联系客户确认安排。

客户可以在“我的 -> 我的邀约”查看预约状态。

### 3.7 查看合同

入口：底部 Tab -> 合同

客户可以：

- 查看已签署合同。
- 查看已终止合同。
- 打开合同详情。
- 查看合同编号、合同标题、关联服务人员、合同文件。

第一版不做电子签章，只做合同文件查看。

### 3.8 查看服务订单

入口：我的 -> 服务订单

客户可以查看：

- 服务订单列表。
- 服务人员。
- 服务时间。
- 服务金额。
- 服务状态。
- 后台备注。

### 3.9 购买团购服务

入口：

- 首页 -> 团购推荐。
- 我的 -> 团购服务。

客户可以：

- 查看团购商品列表。
- 查看团购详情。
- 查看正在拼团的人。
- 单独购买。
- 发起拼团。
- 加入别人的拼团。

第一版使用模拟支付，不会调起真实微信支付。

购买后可在“我的 -> 团购订单”查看订单。

### 3.10 查看系统消息

入口：底部 Tab -> 消息

客户可以看到：

- 需求审核通过消息。
- 需求审核拒绝消息。
- 新的阿姨推荐消息。
- 合同创建消息。
- 拼团成功消息。

点击未读消息后会标记为已读。

## 4. 保姆阿姨/服务人员如何使用

当前第一版没有阿姨独立登录端，阿姨不直接进入系统操作。

阿姨的正确使用方式是：

1. 向平台提供资料。
2. 平台管理员在后台录入资料。
3. 管理员审核并维护阿姨状态。
4. 客户在小程序查看阿姨资料。
5. 客户预约面试后，平台工作人员线下联系阿姨。
6. 面试成功后，管理员创建合同和服务订单。
7. 服务过程中，管理员维护服务订单状态。

阿姨需要配合平台提供：

- 基础身份资料。
- 服务分类和服务经验。
- 薪资范围。
- 服务说明。
- 证书资料。
- 工作经历。
- 可面试时间。
- 可服务区域。

如果后续要做阿姨独立端，需要新增：

- 阿姨登录。
- 阿姨资料自维护。
- 接单/拒单。
- 服务状态更新。
- 收入查看。

这些不属于当前第一版范围。

## 5. 推荐的完整业务流程

### 5.1 客户找阿姨流程

1. 管理员录入服务分类和阿姨资料。
2. 管理员上架阿姨。
3. 客户打开小程序首页或找阿姨。
4. 客户筛选并查看阿姨详情。
5. 客户收藏或预约面试。
6. 管理员后台处理预约。
7. 管理员线下沟通客户和阿姨。

### 5.2 发布需求到推荐阿姨流程

1. 客户发布需求。
2. 系统生成“审核中”需求。
3. 管理员后台审核需求。
4. 审核通过后，管理员推荐阿姨。
5. 客户收到系统消息。
6. 客户进入需求详情查看推荐阿姨。
7. 客户预约面试。
8. 管理员线下跟进。

### 5.3 签约和服务订单流程

1. 客户和阿姨线下面试确认。
2. 管理员创建服务订单。
3. 管理员创建合同并上传合同文件。
4. 客户在小程序查看合同和服务订单。
5. 服务开始后，管理员更新订单状态。
6. 服务结束后，管理员改为已完成。

### 5.4 团购流程

1. 管理员创建团购商品并上架。
2. 客户查看团购详情。
3. 客户选择单独购买或发起拼团。
4. 系统模拟支付成功。
5. 单独购买生成“待使用”订单。
6. 发起拼团生成“待分享”订单和“拼团中”记录。
7. 其他客户加入拼团。
8. 满员后拼团成功，订单变为“待使用”。
9. 管理员后台查看和处理团购订单。

## 6. 常见问题

### 6.1 客户为什么看不到某个阿姨？

可能原因：

- 阿姨未上架。
- 阿姨被删除。
- 当前筛选条件不匹配。
- 分类被禁用。

### 6.2 客户为什么看不到推荐阿姨？

可能原因：

- 需求还没有审核通过。
- 管理员还没有推荐阿姨。
- 推荐记录被删除。

### 6.3 小程序为什么显示空数据？

检查：

- 后端 `8081` 是否启动。
- 小程序请求地址是否是 `http://localhost:8081`。
- 测试数据是否已导入。
- 当前用户是否是本地测试用户。

### 6.4 管理后台为什么登录失败？

检查：

- 后端 `8081` 是否启动。
- 管理后台 `8082` 是否启动。
- `/dev-api` 代理是否指向 `http://localhost:8081`。
- 用户名和密码是否正确。

### 6.5 阿姨能不能自己登录？

当前第一版不能。阿姨资料由管理员维护，阿姨通过线下方式配合平台。

## 7. 当前版本使用边界

当前版本适合用于：

- 演示家政服务平台主流程。
- 本地联调和客户验收。
- 验证需求审核、阿姨推荐、预约面试、合同、订单、团购和系统消息。

当前版本不适合直接用于正式生产：

- 未接真实微信支付。
- 未接真实微信手机号授权。
- 未配置正式域名和 HTTPS。
- 未完成真实合同电子签。
- 未完成阿姨独立端。
- 未完成真机全流程验收。
